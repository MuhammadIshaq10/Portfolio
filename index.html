// about

A bit about me

I'm Ishaq, a frontend web developer who enjoys turning rough ideas and Figma files into interfaces that feel quick, clear, and a little bit delightful to use. I care about the details most people scroll past spacing, motion, load times because that's where good UI actually lives.

My day-to-day toolkit is React and Tailwind CSS for building products, and WordPress for clients who need something they can manage themselves. I like working close to designers and learning the "why" behind a layout, not just the "how."

  • Based in Pakistan — open to remote work
  • 1+ years building interfaces for the web
  • Currently exploring Node.js & backend basics
